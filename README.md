# Bias-Aware Skin Disease Synthesis Pipeline

## Overview

### Problem Statement

The datasets for skin diseases highly under-represent darker skin tones, which in turn increases the risks of false negatives and late detection. We aim to develop a pipeline that is reproducible and can be used across different skin diseases. Although the initial project would be focused on melanoma datasets.

### Objectives

To solve the problem, we plan to develop a pipeline that is reproducible and can be used across different skin diseases. Although the initial project would be focused on melanoma datasets.

## Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Muneeb-Ahmad-404/bias-aware-stylegan
cd bias-aware-stylegan
````

### 2. Create Virtual Environment (using uv)

```bash
uv venv

source .venv/bin/activate   # Linux/Mac
.venv\Scripts\activate      # Windows
```

### 3. Install Dependencies (using uv)

```bash
uv sync
```

### 4. Configure DVC Remote

DVC remote storage credentials are configured locally and are not committed to the repository.

Configure DagsHub credentials:

```bash
dvc remote modify --local origin_raw auth basic

dvc remote modify --local origin_raw user <DagsHub-username>

dvc remote modify --local origin_raw password <DagsHub-access-token>
```

### 5. Fetch Dataset via DVC

After datasets are added and the remote is configured:

```bash
dvc pull
```

---

## DVC

* **Remote Storage Used:** DagsHub (DVC remote storage)

* **Data Versioning Workflow:**

  * Data artifacts are generated by pipeline stages.
  * `dvc add` tracks dataset versions locally.
  * `.dvc` metadata files are committed to Git.
  * `dvc push` uploads tracked artifacts to remote storage.
  * `dvc pull` restores datasets from remote storage.
